# Accessibility Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all critical and high severity WCAG 2.1 AA issues from the audit at `docs/superpowers/specs/2026-03-25-accessibility-audit.md`.

**Architecture:** CSS variable changes for contrast, HTML attribute additions for ARIA, JS handler additions for keyboard navigation. All in single file `convocatoria.html`.

**Tech Stack:** Vanilla CSS/HTML/JS. No frameworks.

- [ ] **Step 1: Add visually hidden h1**

